# Production readiness

Required before launch: apply migrations to the selected Supabase project; set real secrets; bootstrap the administrator; configure Resend/SMTP and VAPID and enable Web Push in Admin Configuration; verify private uploads on real devices; exercise tenant isolation and lifecycle permissions; run `npm run typecheck`, `npm run lint`, and `npm run build`; confirm backups and custom-domain TLS. Push notifications require HTTPS and user permission. On iOS 16.4 and later, users must add Opsora to their Home Screen and open the installed PWA before enabling notifications. Android users need a compatible browser such as Chrome. Notification sound and vibration depend on browser, device, and user notification settings; the app can play its alert sound only while open after audio is unlocked by user interaction. No staging, SIT or UAT environment is used.
